# Separated by Degrees: Education & Political Polarization (ESS Round 11)

An empirical research project evaluating the relationship between formal educational attainment (`eduyrs`) and ideological extremity (derived from `lrscale`) across European democracies, with a focused comparative interaction analysis on Greece.

## Key Findings
* **European Baseline:** Additional years of education correlate with slightly higher ideological certainty/firmness ($\beta_1 = +0.0065, p < 0.01$).
* **Greek Context:** Higher educational attainment acts as a moderating force, shifting self-placement toward the ideological center (Net Slope $\beta = -0.0072$).
* **Data Hygiene:** Highlights item-nonresponse patterns—specifically a 46.97% missingness rate in Greek household income responses—and tests model stability via complete-case and full-sample specifications.

## Features
* **Streamlit Dashboard:** Interactive model exploration, missingness audits, and parameter sensitivity controls.
* **Econometric Rigor:** Features Welch's t-tests, HC1 robust standard errors, and baseline interaction modeling.
